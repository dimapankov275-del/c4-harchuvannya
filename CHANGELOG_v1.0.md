# С4 Харчування v1.0.0+16

## Стабільний реліз 1.0

Це перший стабільний реліз застосунку. v1.0 фіксує робочу базу після успішного CI v0.9 і не змінює перевірену логіку харчування або Word-шаблон без необхідності.

### Розрахунки
- Один день або період `З / По`.
- Повідомлення №1 і №2 збережені за поточною логікою.
- Статуси `К`, `В`, `Ш`, `Вд`.
- `190+` автоматично рахується тільки серед осіб із `К`.
- Підтримуються швидкі періоди та копіювання результатів.

### DOCX
- Формування рапортів на одну, кілька або всі вибрані особи.
- Одна людина = одна сторінка.
- Підтримка окремих файлів за групами.
- `Моя тестова сторінка Word` залишається основним редагованим MASTER-шаблоном.
- Ручне оформлення Word зберігається та використовується для наступних документів.
- Резервна копія зберігає також користувацький Word-шаблон.

### Адміністрування
- Ролі: адміністратор, редактор, черговий.
- Редактор обмежений дозволеними групами.
- Черговий працює у режимі перегляду без права редагування статусів.
- Журнал дій із фільтрами.
- Ручні й автоматичні backup.
- Safety-backup перед відновленням та імпортом.
- Відкат останньої масової зміни.
- CSV export/import у локальному режимі.

### Стабільність і реліз
- Версія застосунку: **1.0.0+16**.
- Windows Setup: `C4_Harchuvannya_v1.0.0_Setup.exe`.
- Android: `C4_Harchuvannya_v1.0.0_Android.apk`.
- macOS: `C4_Harchuvannya_v1.0.0_macOS.dmg`.
- GitHub Release перевіряє, що tag точно відповідає версії з `pubspec.yaml`.
- Додано regression-тест узгодженості релізних файлів.
- Auto-backup не блокує старт застосунку.
