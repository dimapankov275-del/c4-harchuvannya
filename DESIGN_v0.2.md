# С4 Харчування — UI v0.2

Ця версія повністю переробляє візуальний напрямок під затверджений концепт:
темно-синій інтерфейс, ліве меню на ноутбуці, верхня панель, кольорові швидкі дії,
картки статистики, мобільна нижня навігація та великі touch-елементи.

## Основні принципи

- Темна тема — основна, світла тема — альтернативна.
- Один дизайн для Windows/macOS та Android, але різне компонування під розмір екрана.
- Мінімум декоративного шуму: інформаційні картки, чітка ієрархія, великі активні зони.
- Статуси мають і колір, і текст: К / В / Ш / Вд.
- На десктопі: sidebar + topbar + dashboard.
- На телефоні: compact header + bottom navigation + 2-column quick actions.
- Жодних гасел або напису «Разом до перемоги».

## Кольорові ролі

- Синій — основна дія / Telegram / навігація.
- Зелений — успішна дія / синхронізація / К.
- Жовтий — В.
- Червоний — Ш.
- Синій/фіолетовий — Вд.
- Помаранчевий — розрахунки / акцент.
