# v0.5.0 — Оновлення застосунку

- Автоматична перевірка GitHub Releases при запуску застосунку.
- Вікно «Доступне оновлення» з номером версії та коротким списком змін.
- Окремий файл інсталяції під Windows, Android та macOS.
- Ручна перевірка оновлень у «Налаштування → Оновлення застосунку».
- Підтримка обов’язкового оновлення через `update-policy.json`.
- GitHub tag `v*` автоматично створює Release з Setup.exe, APK, DMG та SHA256SUMS.txt.
- Усі звичайні Snackbar-повідомлення закриваються через 5 секунд.
- Нове Snackbar-повідомлення очищає попереднє, щоб повідомлення не накопичувались.

Backend Apps Script v0.4 змінювати для цього релізу не потрібно.
