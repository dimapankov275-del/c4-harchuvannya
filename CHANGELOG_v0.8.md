# C4 Харчування v0.8.0+9

Об'єднаний реліз функцій, які планувалися для v0.7 і v0.8.

## Збережено з v0.6
- Розрахунок на один день і період `З / По`.
- Швидкі періоди та копіювання розрахунків.
- Статуси К / В / Ш / Вд.
- Автоматичний підрахунок `190+` серед К для фіксованого списку.

## Нове — рапорти DOCX
- Реальне формування рапорту на компенсацію з MASTER DOCX-шаблону.
- Форматування Word береться з шаблону, а не створюється з нуля.
- Компенсація формується тільки за позначками `К`; сума у гривнях не рахується.
- Вибір періоду `З / По`.
- Вибір однієї групи або всіх доступних груп.
- Вибір конкретних осіб перед формуванням.
- Попередній перегляд: ПІБ, група, кількість прийомів та текст компенсації.
- Одна особа = одна сторінка.
- Для режиму «Всі» можна створити окремий DOCX для кожної групи С-41…С-45.
- Довідник 128 осіб містить повні ПІБ, давальний відмінок, посади та звання для формування документа.

## Документи і надсилання
- Відкрити сформований DOCX у Word/системній програмі.
- Зберегти копію у Downloads / Documents.
- `Telegram / Поділитися` через системне меню надсилання файлів.
- Можна поділитися одним DOCX або всіма сформованими файлами.
- Локальна історія формування, відкриття, збереження і виклику меню надсилання.

## Налаштування рапорту
Адміністратор може змінювати:
- адресатів;
- начальника курсу;
- текст третього клопотання;
- підписантів;
- блок «ПОГОДЖЕНО».

## Версія / збірки
- App version: `0.8.0+9`.
- Windows installer: `C4_Harchuvannya_v0.8.0_Setup.exe`.
- Android: `C4_Harchuvannya_v0.8.0_Android.apk`.
- macOS: `C4_Harchuvannya_v0.8.0_macOS.dmg`.

- Windows CI fix: Word template asset renamed to ASCII `report_template.docx` to avoid Windows/Inno Setup path-length failure.
